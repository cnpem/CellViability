# Welcome to the **CellViability** Package Documentation

## Overview

**CellViability** is a package designed to support the analysis of cell viability assays from **TIFF** images containing nuclear staining. The package was developed with the data volume and processing demands typical of High-Content Screening(HCS) and High-Throughput Screening (HTS) workflows in mind. Using the images and a configuration file (`config.json`), the package performs the full processing and analysis workflow in an automated and consistent manner.

*Note:** Currently, the package is configured to process **only** data exported in the **Columbus server** format and is limited to **384-well plates**. Support for additional plate formats may be added in future updates.

This documentation is organized in a clear and objective way to support users with different levels of experience in image-based cell analysis.
