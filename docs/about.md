# About

CellViability is a package designed to support the analysis of cell viability assays from TIFF images containing nuclear staining.
It was developed to handle the data volume and processing requirements commonly found in High-Content Screening (HCS) and High-Throughput Screening (HTS) workflows.

Using TIFF images and a configuration file (config.json), the package performs the entire processing and analysis pipeline in an automated, reliable, and reproducible manner.
