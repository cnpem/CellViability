# Relatório: Implementação de protocolo de processamento de imagens em ensaios fenotípicos de viabilidade celular

This repository contains the LaTeX source code and figures for the report of the research project "Implementação de protocolo de processamento de imagens em ensaios fenotípicos de viabilidade celular", written by the candidate [@KayllanyLara](https://github.com/KayllanyLara) and the supervisor [@jvsguerra](https://github.com/jvsguerra).

## Dependencies

To install the dependencies, run:

```bash
sudo apt-get install texlive-base texlive-latex-recommended texlive-latex-extra texlive-science texlive-font-utils texlive-lang-spanish texlive-publishers texlive-pictures abntex biber
```

## Building the report

To generate the report, run:

```bash
make build
```

To remove intermediate files and clean up the directory, run:

```bash
make cleanup
```
